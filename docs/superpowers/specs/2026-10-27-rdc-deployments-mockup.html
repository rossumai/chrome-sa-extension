Bring tested configuration into Acme

Copy queues, schemas, hooks, rules and labels from another organization into this one. You see every change before anything is written.

  1. Choose the one org that Acme deploys from, usually your test org.
  2. Give a token for it. It is only read, and the token is not kept.
  3. Review what will change in Acme, then write it.
Why start here, in Acme?
Each organization has its own data storage, so each one keeps its own record: where it gets configuration from, what it keeps for itself, and what was deployed into it. To deploy into another org, open the Console from that org. 2
